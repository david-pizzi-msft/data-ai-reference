# Digital twin builder in RTI — Fabric Git folder

Git integration target for the **Digital twin builder (preview) in Real-Time Intelligence** end-to-end
tutorial workspace. Fabric serializes the workspace's item definitions (digital twin builder, lakehouse,
eventstream, eventhouse/KQL database, notebook, KQL queryset, Real-Time Dashboard) into this folder on commit.

- **Fabric Git folder path:** `/git/end-to-end/digital-twin-builder-rti`
- **Source tutorial:** [Digital twin builder (preview) in Real-Time Intelligence tutorial](https://learn.microsoft.com/en-us/fabric/real-time-intelligence/digital-twin-builder/tutorial-rti-0-introduction)
