# Data warehouse — Fabric Git folder

Git integration target for the **Data warehouse** end-to-end tutorial workspace. Fabric serializes
the workspace's item definitions (warehouse, data pipeline, semantic model, Power BI report,
notebook) into this folder on commit.

- **Fabric Git folder path:** `/git/end-to-end/data-warehouse`
- **Source tutorial:** [Data warehouse end-to-end tutorial](https://learn.microsoft.com/en-us/fabric/data-warehouse/tutorial-introduction)
