# Lakehouse — Fabric Git folder

Git integration target for the **Lakehouse** end-to-end tutorial workspace. Fabric serializes the
workspace's item definitions (lakehouse, notebooks, pipelines, semantic model, report) into this
folder on commit.

- **Fabric Git folder path:** `/git/end-to-end/lakehouse`
- **Source tutorial:** [Lakehouse end-to-end scenario](https://learn.microsoft.com/en-us/fabric/data-engineering/tutorial-lakehouse-introduction)
