# Data Factory — Fabric Git folder

Git integration target for the **Data Factory** end-to-end tutorial workspace. Fabric
serializes the workspace's item definitions (Copy job, Lakehouse, Dataflow Gen2, Data pipeline)
into this folder on commit.

- **Fabric Git folder path:** `/git/end-to-end/data-factory`
- **Source tutorial:** [Data Factory end-to-end tutorial](https://learn.microsoft.com/en-us/fabric/data-factory/tutorial-end-to-end-introduction)
