# Real-Time Intelligence — Fabric Git folder

Git integration target for the **Real-Time Intelligence** end-to-end tutorial workspace. Fabric
serializes the workspace's item definitions (eventhouse, KQL database, eventstream, KQL queryset,
Real-Time Dashboard, Activator) into this folder on commit.

- **Fabric Git folder path:** `/git/end-to-end/real-time-intelligence`
- **Source tutorial:** [Real-Time Intelligence end-to-end tutorial](https://learn.microsoft.com/en-us/fabric/real-time-intelligence/tutorial-introduction)
