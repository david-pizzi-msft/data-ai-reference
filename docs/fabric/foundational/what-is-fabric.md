# What is Microsoft Fabric?

[Official docs](https://learn.microsoft.com/en-us/fabric/fundamentals/microsoft-fabric-overview)

Unified SaaS analytics platform covering ingestion, transformation, storage, real-time processing, data science, and BI.

## Key points

- Single SaaS platform — no infrastructure to manage
- **OneLake** as the unified data lake for the whole tenant
- Workloads: Data Engineering, Data Factory, Data Warehouse, Real-Time Intelligence, Data Science, Power BI
- Copilot built in across experiences
