# DP-600: Implement Analytics Solutions Using Microsoft Fabric

> **Level:** Advanced · **Duration:** 4 days · **Certification:** Fabric Analytics Engineer Associate

The [DP-600T00 course](https://learn.microsoft.com/en-gb/training/courses/dp-600t00) covers preparing, enriching, and serving data for analysis across lakehouses, warehouses, and eventhouses in Microsoft Fabric.

## Learning Paths

<div class="grid cards" markdown>

- **[1 · Explore analytics data stores](explore-data-stores.md)**

    Lakehouses, warehouses, eventhouses, SQL analytics endpoints.

- **[2 · Design and transform analytics data](transform-data.md)**

    Dataflows, notebooks, T-SQL, data transformation patterns.

- **[3 · Design and manage semantic models](semantic-models.md)**

    Dimensional modelling, DAX, semantic model optimisation.

- **[4 · Prepare AI-ready analytics data](ai-ready-data.md)**

    Data prep for AI agents and Copilot experiences.

- **[5 · Secure and govern analytics data](secure-govern.md)**

    RLS, workspace security, governance, lifecycle management.

</div>
