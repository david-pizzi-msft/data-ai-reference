# 4 · Build a Fabric data agent with an ontology

> **Module 4 of 4** · 7 units

Create a Fabric data agent that uses a Fabric IQ ontology as its data source. Configure agent instructions to improve query accuracy, test natural-language questions, and publish the agent so business users get governed data answers without writing code.

## Introduction

Final step in the **Lamna Healthcare** scenario: data is consolidated into a lakehouse and eventhouse, and the Fabric IQ ontology models the hospital domain. Now you build a **data agent** on top of that ontology — create it, connect the ontology, configure instructions, test with natural-language questions, and publish it so colleagues can ask questions and get answers directly from the data.

By the end of this module you'll be able to:

- Explain how an ontology provides business vocabulary that a data agent uses as a data source.
- Create a Fabric data agent and connect it to an ontology.
- Configure agent instructions to improve query accuracy.
- Test responses by asking natural-language questions and reviewing the generated queries.
- Publish a data agent to make it available to colleagues.

## Summary

You learned to build a Fabric data agent that uses an ontology as its data source. The ontology defines the entity types and relationships that give the agent the context to translate natural language into **GQL** queries. You connected the ontology as a data source, wrote **agent instructions** to guide interpretation, used the **steps dropdown** to validate how the agent reasons through a question, then published and shared the agent.

This completes the Get Started learning path: **define** business vocabulary in an ontology, **bind** it to data, **explore** it visually, and **expose** it through a natural-language data agent.
