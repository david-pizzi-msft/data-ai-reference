# Data Agent

A **Fabric data agent** is a configurable, generally available artifact that turns governed data in OneLake into a conversational Q&A system. People ask plain-English questions and get structured answers — no SQL, DAX, or KQL required. In the Fabric IQ context, an **ontology** can be one of its data sources, grounding answers in shared business semantics.
